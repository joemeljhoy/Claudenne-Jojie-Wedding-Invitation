==================================================
MUSIC
==================================================

Keep the exact MP3 filename:

Over October - Intertwine (Official Lyric Video) ft. The Ridleys.mp3

The music starts after the guest taps the wax seal.

This is required because Chrome, Safari, Edge, and mobile browsers
normally block music before the visitor interacts with the page.

==================================================
GITHUB PAGES
==================================================

1. Open the GitHub repository:
   Jojie-Claudenne-Wedding-Invitation

2. Upload all files to the repository root.

3. Commit the changes.

4. Open Settings.

5. Open Pages.

6. Under Build and deployment, choose:
   Deploy from a branch

7. Select:
   Branch: main
   Folder: / (root)

8. Click Save.

9. Wait approximately 2 to 5 minutes.

10. Open the published website in an Incognito or Private window
    to avoid seeing the previous cached design.
