IMPORTANT:

- Replace "your-email@example.com" in index.html with the real RSVP email, or replace the whole mailto link with a Google Form link.
- Replace all placeholder names, times, and events directly in index.html.
- The song starts only after the guest taps the seal. This is required by modern browser autoplay rules.
- The website pauses audio when the guest leaves the tab/page.

GITHUB PAGES:
1. Open repository: Jojie-Claudenne-Wedding-Invitation
2. Upload all five files to the repository root, not inside another folder.
3. Go to Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch "main" and folder "/ (root)", then Save.
6. Wait a few minutes for the public website link.
